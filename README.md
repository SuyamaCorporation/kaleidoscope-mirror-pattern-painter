# カレイドスコープ対称パターン画家

マウスで描いた線をカレイドスコープ対称（6/8/12/16倍）でリアルタイム反射描画するアート生成ツール。

## 機能

- 対称数の選択（6/8/12/16倍）
- ブラシ色・サイズ・透明度の調整
- 背景色の変更
- キャンバスのクリア
- PNG形式での保存
- タッチデバイス対応

## 技術仕様

- Canvas 600×600
- 中心からの極座標計算で全対称位置に同一ストロークを描画
- X軸ミラー反射も同時適用（各対称ごと）
- requestAnimationFrame 不使用（mousemove イベント駆動）
- バニラJS / Tailwind CDN のみ
